# Modelo de negocio — Debales

## Modelo comercial previsto

La plataforma se vende por combinación de:

| Dimensión          | Descripción                                      |
|--------------------|--------------------------------------------------|
| Cliente            | Licencia por empresa instalada                   |
| Instalación        | Coste de puesta en marcha                        |
| Usuarios           | Precio por usuario activo                        |
| Módulos activos    | Suscripción por módulo contratado                |
| Uso de IA          | Cuota según volumen de consultas/propuestas IA   |
| Soporte            | Nivel de SLA contratado                          |
| Personalización    | Desarrollos a medida                             |
| Mantenimiento      | Actualizaciones y parches                        |

## Escenarios de despliegue

1. Local/on-premise en infraestructura del cliente.
2. Servidor privado del cliente.
3. Nube privada gestionada por Debales.
4. SaaS gestionado por Debales.

## Roles en la empresa proveedora

| Rol                  | Responsabilidad principal                                      |
|----------------------|----------------------------------------------------------------|
| Responsable cliente  | Relación, priorización, traducción de necesidades              |
| Experto funcional    | Validación de procesos y propuestas funcionales                |
| Experto técnico      | Revisión de arquitectura, migraciones y despliegues            |
| Supervisor IA        | Mantenimiento de prompts, agentes y calidad de respuestas      |
